# Personajes auténticos: entrada controlada

No hay personajes aprobados para esta versión. **No añadir imágenes de sitios oficiales únicamente porque sean accesibles públicamente.** Para incluir uno, aportar PNG recortado con transparencia y evidencia comprobable de permiso de uso y transformación de la imagen en esta web.

Archivos opcionales: `left.png`, `right.png`, `rights.json` (esquema en `rights.example.json`). Solo usar `permission:granted` con prueba verificable. El renderizador ignora material no autorizado y nunca fabrica personajes.
